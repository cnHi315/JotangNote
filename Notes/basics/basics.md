# 基础知识笔记

## 一、HTTP 请求与响应

---

1. 一个标准的 HTTP 请求和响应，都有哪些部分？
   都是四部分：请求行或状态行、头、空行、体。
2. 提交一篇长篇笔记该用哪种方法？为什么？
   POST 。GET 的参数只能塞在 URL 里，长度有限，语义也只读。
3. 常见状态码有哪些？JotangNote 里会用到哪些？
   200 成功、400 参数错、401 未登录、403 无权限、404 不存在、429 太频繁、500 服务器错。

---

### 1. 请求和响应

请求四部分：请求行、请求头、空行、请求体。

```http
GET /notes/1 HTTP/1.1
Host: localhost:8080
token: eyJhbGciOiJIUzI1NiJ9...
```

响应也是四部分，第一行换成状态行。

```http
HTTP/1.1 200 OK
Content-Type: application/json;charset=utf-8

{"code":200,"msg":"success","data":{...}}
```

方法、路径、版本写在请求行，要提交的数据写在请求体。

### 2. 为什么提交长笔记用 POST

- 正文太长，URL 放不下。
- GET 的语义是只读。用它改数据，浏览器预加载、刷新、爬虫抓取都会重复触发。
- GET 的参数会进浏览器历史和服务器日志，不适合传正文，更不适合传密码。

新建和更新是两个方法。项目里新建用 `POST /notes` ，更新用 `PUT /notes/{id}` 。

### 3. 状态码

三位数，第一位是类别。

- 1xx 信息，见不到
- 2xx 成功
- 3xx 重定向
- 4xx 客户端出错
- 5xx 服务端出错

常见的：200 成功、301 永久重定向、304 资源没变、400 参数不合法、401 没登录、403 没权限、404 不存在、429 太频繁、500 服务端出错、502 网关拿不到响应、503 服务不可用。

JotangNote 用到的：200 成功、400 参数不合法、401 没带 token 或解析失败、403 改别人的笔记、404 笔记不存在或私密笔记被非本人访问、429 模型限流、500 服务器内部错误。

>这些码在项目里全都返回 HTTP 200 ，真正的值以业务码的形式放在统一返回类型的 Result 里。前端统一判断方便，不过不符合 HTTP 语义，监控看不出错误率。

## 二、接口 / API

---

1. 设计"获取某篇笔记详细内容"的接口，要考虑什么？
   路径和方法、参数放哪、鉴权、权限、返回结构、敏感字段、缓存、错误码。

---

### 获取某篇笔记详细内容

路径和方法定成 `GET /notes/{id}` 。路径用名词表示资源，方法表示动作。

- 参数放哪。id 标识唯一资源，放路径里。
- 鉴权。除了登录注册，其余都要过拦截器。
- 权限。公开的谁都能看，私密的只有本人。资源不存在和权限不足应同时返回 404，以免存在信息泄露。
- 返回结构。统一用 `Result` 包一层。
- 敏感字段。User 的 password 绝不能出现在响应里。
- 缓存。查过的笔记可以缓存。
- 错误码。id 不存在返回 404 ，不返回一个空 Note 。

>权限最容易被漏掉。前端能把按钮藏起来，但请求照样发得出来，所以服务端每个接口都要自己判一次。

## 三、JSON

---

1. JSON 格式的数据长什么样？
   对象 `{}` 、数组 `[]` ，键必须双引号。
2. Java 里怎么把对象转成 JSON，或者反过来？
   用 Jackson 的 JsonMapper 手动转，或者标 `@RequestBody` 让 Spring 自动转。

---

### 1. 长什么样

```json
{
    "id": 1,
    "title": "第一篇",
    "isPublic": true,
    "tags": ["java", "spring"],
    "author": {"id": 2, "username": "cnHi"},
    "deletedAt": null
}
```

只有两种结构，对象 `{}` 和数组 `[]` 。值可以是字符串、数字、布尔、null 、对象、数组。

规矩：键必须双引号；最后一个键值对后面不能有逗号；不能写注释。

### 2. Java 里怎么互转

```java
String json = jsonMapper.writeValueAsString(note);    // 对象转 JSON
Note note = jsonMapper.readValue(json, Note.class);   // JSON 转对象
```

大部分时候不用手写，Spring MVC 会代劳。参数标 `@RequestBody` 自动转成对象，返回对象自动转成 JSON 。

字段名和键名不一致时加 `@JsonProperty` 。项目里 `AIMessage` 的字段就叫 `tool_calls` ，下划线直接当键名，不用注解。

>Spring Boot 4 带的是 Jackson 3，core 和 databind 在 `tools.jackson` 包下，但注解还留在 `com.fasterxml.jackson.annotation` ，导入容易混。

## 四、HTTPS

---

1. HTTPS 的加密过程是怎么样的？
   混合加密。先验证书，再用服务器公钥把对称密钥送过去，之后用对称密钥传数据。

---

### 加密过程

握手六步：

1. 客户端发起连接，说明自己支持哪些加密算法。
2. 服务器返回证书，里面有公钥，由 CA 用私钥签过名。
3. 客户端用系统内置的 CA 公钥验签，确认公钥属于这个网站。
4. 客户端生成随机对称密钥，用服务器公钥加密后发过去。
5. 服务器用私钥解密，拿到对称密钥。
6. 之后双方用对称密钥加密数据。

两种加密都用的原因：非对称加密安全但慢，只用来换密钥；对称加密快，用来传数据。

证书防的是中间人。没有证书，攻击者能把自己的公钥冒充给客户端，之后的流量全被解密。

>本地开发 http 够用。上线一般在前面的 Nginx 做 HTTPS 终止，后端还是 http 。
